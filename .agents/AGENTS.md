# Project-Scoped Rules

<RULE>
1. Jangan pernah mem-*push* atau memodifikasi folder `Jurnal/` ke *remote repository* (GitHub). Folder ini eksklusif digunakan untuk menyimpan dokumen/berkas riset dan jurnal pengguna yang tidak ditujukan untuk publikasi *open source*. Folder ini sudah diatur dalam `.gitignore`.
</RULE>

<RULE>
2. Ingat bahwa proyek ini bernama **PINTAR KBLI** (bukan lagi DEMAKAI). Aplikasi ini berfokus pada sistem klasifikasi KBLI 2025 untuk Sensus Ekonomi 2026, menggunakan algoritma Hybrid Search (Semantik + Kata kunci), dan memiliki keunggulan pendekatan kalimat utuh, presisi yang berkembang organik lewat crowdsourcing, serta pencarian yang user-friendly.
</RULE>
